# Infinite Explorer — Solar System

A lightweight interactive Solar System landing page for GitHub Pages.

## Features
- All eight planets
- Selectable planets with educational descriptions
- CSS-built planets and Saturn's rings
- Responsive layout
- No build step or external dependencies

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder.
3. In **Settings → Pages**, choose the main branch and root folder.
4. Save and open the generated Pages URL.
