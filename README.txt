INFINITE EXPLORER — STARTER PROJECT
===================================

This is a beginner-friendly Progressive Web App (PWA) starter. It includes:
- Responsive home screen for Android and desktop
- Six exploration destinations
- Interactive scale slider
- Install prompt where supported
- Service worker for basic offline caching

IMPORTANT
Opening index.html directly from the Files app lets you preview the design, but installation and offline features need the project to be hosted on HTTPS (or localhost). This is a prototype: it does not yet contain real 3D models, a true infinite-zoom engine, user accounts, or monetization.

FREE PHONE-FRIENDLY ROUTE
1. Extract this ZIP into a folder.
2. Create/sign in to a GitHub account in your browser.
3. Create a new public repository named infinite-explorer.
4. Upload all files from this folder (not the ZIP itself) to the repository root.
5. In the repository, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
7. Wait for the published Pages URL. Open it on Android Chrome.
8. Use Chrome menu > Add to Home screen or Install app if offered.

If you cannot upload multiple files easily from your phone, tell ChatGPT what screen you see and ask for the next step. Do not share your password or verification codes.

NEXT DEVELOPMENT STEPS

5. Consider monetization only after users find the app useful. Possible later options include a paid educational pack or voluntary support; income is not guaranteed.

TECH NOTES
- Built with HTML, CSS, and vanilla JavaScript.
- The Google Fonts import needs internet; system fonts will be used if unavailable.
- Scientific facts are simplified for a first prototype and should be checked before educational publication.
