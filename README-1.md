# Infinite Explorer v2

GitHub Pages-ready Three.js experience.

## Included
- True textured Earth using Three.js
- Cloud layer + atmosphere + Moon
- Orbit camera controls: drag + wheel/pinch
- All eight planets and Saturn's rings
- Clickable planet facts
- Scale navigation: Universe → Solar System → Earth → Life → Cell → Atom
- Responsive mobile UI
- No build step

## Deploy
Upload all files to the repository root. In GitHub:
Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

The project uses Three.js and Earth textures from public Three.js CDN URLs, so the GitHub Pages site needs internet access.
